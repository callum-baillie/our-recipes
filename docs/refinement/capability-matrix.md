# Capability matrix

The inventory in [inventory.json](inventory.json) locates the current web routes, native routes, application APIs, services and curated assistant operations. This matrix describes user workflows rather than counting HTTP verbs. A POST lookup is a read. Device rendering, deployment readiness and live provider quality are separate from source presence and deterministic contract evidence.

The native API uses the existing authenticated session contract and secure credential storage. API keys retain their explicit resource/action allowlist and do not acquire browser sessions or private chat/Nutrition administration access. Binary exports, credential changes, recovery/reset, installation secrets and paid-request consent retain deliberate protected UI handoffs rather than giving the assistant elevated credentials.

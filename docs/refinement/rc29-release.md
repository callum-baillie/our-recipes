# RC29 Add to pantry page and Pantry edit mode

RC29 replaces the Pantry add dialog and the physical count page with a full-width Add to pantry page and a View/Edit toggle on Pantry. It changes no schema (`0082_scanner_stations` / 84 migrations), key, permission or scanner binding. See the release notes for the full list and the verification that was and was not performed.
